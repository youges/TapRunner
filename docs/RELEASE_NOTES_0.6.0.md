# TapRunner 0.6.0

本版重点改善跨页面点位录入和多步骤回放。

- 悬浮栏 ＋ 现在会同时记录并执行点击，支持长按与直线滑动，可跟随页面跳转录入下一点。
- 自动保留相邻动作的录入时间；超过一分钟的等待拆成间隔与等待步骤。
- 新增撤销上一点、可拖动紧凑录入控制框和完成并保存。
- 新建多点脚本默认执行一轮，避免跨页脚本盲目重复；仅标位置仍可在更多菜单使用。
- 修复改变步骤类型后遗留子步骤字段可能隐藏顶层动作的问题；新点插入末尾停止步骤之前。
- 回放时临时隐藏覆盖触点的本应用悬浮层，减少系统成功回调但目标未收到点击的情况。
- 设置页版本号跟随构建版本。

旧脚本与原有权限不自动修改。旧的短间隔跨页脚本建议重新录入或加入等待。坐标录入不能保证网络页面加载完成，也不支持曲线或多指轨迹。

发布包关闭 debuggable，无广告、无互联网权限，数据保存在本机。正式版与开发调试版签名不同。
