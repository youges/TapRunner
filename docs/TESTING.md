# 0.5.1 验证记录

验证日期：2026-10-14。0.5.1 是首个公开发布版本，包含 0.5.0 的界面、主题和性能改进，以及无障碍重连提示修复。

## 构建与静态检查

环境：JDK 21、Gradle 8.13、Android Gradle Plugin 8.13.2、Kotlin 2.1.20、compile/target SDK 36，min SDK 30。

debug/release 均构建成功。两种构建的 Android Lint 均为 **0 错误、0 警告**，构建日志未报告编译警告。release 显式关闭 debuggable；debug 保留调试能力。

核心 JVM 测试 **78 项通过，0 失败、0 错误、0 跳过**：引擎 49、草稿 16、脚本管理 7、显示进度 2、连接恢复 4。连接恢复测试覆盖空闲重连、已完成运行保留、暂停中断后不自动恢复，以及不覆盖其他故障。

发布签名校验通过。正式版证书 SHA-256：`8b6e7706795367a41175cc6c5af9a8425c576a902c0ffdf894e7d590bbea762e`。正式版与开发调试版证书不同，不支持相互覆盖安装。

## 手机验证

设备：vivo X200s（V2458A）、Android 16、1260×2800，系统字体缩放 1.12。

0.5.0 在同一设备完成以下验证：

- 同签名覆盖更新成功，更新前后已保存脚本与偏好文件 SHA-256 一致。
- 白天、暗夜、跟随系统主题切换；预设与自定义配色保存；无效颜色禁止提交。
- 自带测试页实际接收 **100/100 次点击**，末尾等待接收计数校验通过。
- **10/10 次滑动完成**，测试页面记录 625 次滚动回调，最终状态 FINISHED。
- 应用进程的错误日志检查未发现 AndroidRuntime 或本地日志写入错误。

0.5.1 同签名覆盖安装成功，安装前后所有当时存在的脚本与偏好文件校验一致。空闲时服务经历解绑、重新连接后，首页显示「无障碍 · 已连接」，不会继续显示先前的断开故障。

0.5.1 的最后一轮 100 次点击/10 次滑动复测因用户暂停手机测试而未执行，不能把 0.5.0 的手势数据当作 0.5.1 新测结果。正式签名 APK 已完成构建和签名检查，手机测试使用调试签名 APK。

窗口合计帧数不能换算为单一界面 FPS。旧版只有非受控累计数据，不能据此计算优化百分比。样本短、使用调试包且设备开启了其他无障碍服务，不能代表其他手机或目标应用；滑动场景的 P99 仍有慢帧。

优化覆盖异步日志写入、列表惰性布局及稳定键、窗口更新按显示帧合并、重复标记计算减少、控件扫描提前结束和图像文件后台读取。执行时仍保留安全检查与串行手势回调，不强制改变手机刷新率。
