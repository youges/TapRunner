# TapRunner 0.5.1 · 首个公开发布版本

本版本包含 0.5.0 的主题和性能改进，并修复首页保留过期无障碍断开提示的问题。

- 重整首页、脚本库和设置页，加入白天、暗夜、跟随系统主题，四种预设强调色及自定义颜色。
- 保留紧凑悬浮编辑器，加入与主界面一致的明暗与配色。
- 将日志写入移至后台，减少重复脚本扫描、控件扫描、窗口更新和界面刷新；点击与滑动继续等待实际手势回调。
- 清理编译和 Android Lint 警告；移除直接申请电池优化豁免的权限，改用系统设置列表。
- 首页连接标识实时更新。空闲时服务短暂重连不再把已完成运行改成故障；运行期间断开仍会停止，恢复后提示手动重新开始。
- 新增往返滑动测试区和连接恢复回归测试。

核心测试 78 项通过，debug/release 构建成功，Lint 零错误、零警告。首次公开发布保留 0.x 版本号，详细使用方法与已知边界见 [使用说明](USER_GUIDE.md) 和 [验证记录](TESTING.md)。

正式发布包关闭 debuggable，使用独立发布签名。手机上的开发调试版不能直接用正式版覆盖，请先导出脚本再换装。密钥和密码不在仓库中。
