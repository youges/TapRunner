# 自动连点器编辑逻辑对照（0.6.0）

分析对象：手机上安装的自动连点器 1.4.8（code 53）。本机原始 base.apk 与手机 SHA-256 一致：eee0b9f91b25b2513983259fddc24e2467a2baa6a860be324670c0efb890e3b0。原 APK 未修改，也未重打包。

使用 REA 6.4.0 与 JADX headless 0.7.1 完成静态有限追踪。服务将场景数据交给悬浮控制菜单；不同动作类型对应不同浮动动作对象，并按索引替换旧对象。已找到点位展示、动作对象和场景模型，但未完整追到触摸捕获、透传或回放、落盘的整个调用链。

因此，不能将“点击即录入并操作页面”说成已由第三方静态代码完全证明。本轮 TapRunner 按用户描述独立实现这一交互，再使用自身两页测试场景验证实际接收情况。没有复制第三方源码，没有将其 APK 或反编译源码纳入工程或公开发布包。

仍未解析的入口包括浮动菜单若干混淆方法与动作对象的触摸处理。完整 REA Evidence ID 及原始结果仅保留在本地验证材料中。
